2. Fundamentos de Estilo y el Modelo de Caja (CSS3)

La web moderna se construye sobre dos pilares fundamentales: estructura y presentación. En este curso, abordaremos el desarrollo web no como la simple memorización de etiquetas, sino como la construcción de sistemas de información accesibles. HTML (HyperText Markup Language) nos permitirá definir el significado y la estructura del contenido, mientras que CSS (Cascading Style Sheets) nos dará el poder de controlar la apariencia visual, la tipografía y la adaptación a diferentes dispositivos. Este curso elimina las prácticas obsoletas y se centra exclusivamente en estándares actuales.

Módulo 2: Fundamentos de Estilo y el Modelo de Caja (CSS3)

Enfoque: Controlar el espacio y la apariencia visual básica.

Temario

  • Sintaxis CSS y formas de inclusión (In-line, Internal, External).
  • Selectores: Clases, IDs, Descendientes y Pseudoclases (:hover, :focus).
  • El Modelo de Caja (Box Model): Margins, Borders, Padding y Content. La importancia de box-sizing: border-box.
  • Tipografía web (Google Fonts) y Unidades de medida (px, rem, em, %, vh/vw).
  • Formularios modernos y validaciones nativas.

Ejemplo en clase: Estilizar el artículo de blog del Módulo 1 (colores, fuentes y espaciado).

Práctica guiada: Crear "Tarjetas de Producto" (Cards) con bordes redondeados y sombras.

Tarea autónoma: Aplicar estilos completos a la "Hoja de Vida" del Módulo 1, asegurando una paleta de colores coherente y tipografía legible.
