4. Responsive Design y Técnicas Avanzadas

El diseño responsivo es una técnica de desarrollo web que adapta la presentación de un sitio a cualquier tamaño de pantalla (ordenadores, tabletas, teléfonos), basándose en los fundamentos de grillas fluidas, imágenes fluidas y media queries. Las técnicas avanzadas incluyen el uso de unidades relativas, rejillas fluidas, CSS Grid y flexbox, además de considerar factores como la orientación, el tipo de puntero y la personalización del contenido para mejorar la experiencia del usuario en diversos dispositivos.

Módulo 4: Responsive Design y Técnicas Avanzadas

Enfoque: Adaptabilidad a móviles y pulido visual. profesionalmente.

Temario

  • El Viewport meta tag.
  • Media Queries: Puntos de ruptura (Breakpoints) para móvil, tablet y escritorio. (justify-content, align-items). Ideal para componentes lineales.
  • Estrategia Mobile First vs Desktop First.
  • Introducción breve a animaciones y transiciones CSS (transition, transform).
  • Formularios modernos y validaciones nativas.

Ejemplo en clase: Hacer que la Landing Page del Módulo 3 se adapte perfectamente a un teléfono móvil (menú hamburguesa, columnas apiladas).

Práctica guiada: Maquetar una Landing Page básica con cabecera, sección de servicios (3 columnas) y pie de página.

Tarea autónoma (Proyecto final): Desarrollar un sitio web personal multipágina (Inicio, Sobre mí, Portafolio, Contacto) que sea 100% responsivo, utilice tipografías externas y tenga al menos una animación suave al pasar el mouse.
