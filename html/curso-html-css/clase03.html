3. Flexbox y Grid

Flexbox Su especialidad: Acomodar cosas en una sola dirección (una fila O una columna). Imagínalo como un collar de perlas: tú decides si el hilo va horizontal o vertical, y cómo se distribuyen las perlas a lo largo de ese hilo. Grid: Su especialidad: Acomodar cosas en dos direcciones al mismo tiempo (Filas Y Columnas). Imagínalo como un tablero de ajedrez o una hoja de Excel. Tú defines la cuadrícula y luego dices "quiero que este elemento ocupe desde la celda A1 hasta la B2".

Módulo 3: Diseño de Layouts Modernos (Flexbox y Grid)

Enfoque: Enfoque: Dejar atrás los floats y aprender a posicionar elementos profesionalmente.

Temario

  • Posicionamiento (Static, Relative, Absolute, Fixed, Sticky)
  • Flexbox: Ejes principales y cruzados, alineación y distribución de espacio (justify-content, align-items). Ideal para componentes lineales.
  • CSS Grid Layout: Creación de grillas bidimensionales (filas y columnas), áreas de grid y gap. Ideal para maquetación general.
  • Tipografía web (Google Fonts) y Unidades de medida (px, rem, em, %, vh/vw).
  • Formularios modernos y validaciones nativas.

Ejemplo en clase:

  1. Crear una barra de navegación responsiva con Flexbox.
  2. Crear una galería de imágenes tipo "Pinterest" con Grid.

Práctica guiada: Maquetar una Landing Page básica con cabecera, sección de servicios (3 columnas) y pie de página.

Tarea autónoma: Diseñar el layout de una página de "Dashboard" o Panel de Control, utilizando Grid para la estructura principal y Flexbox para los menús internos.
