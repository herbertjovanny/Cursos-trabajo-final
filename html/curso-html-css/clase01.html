1. Introducción a Html

La web moderna se construye sobre dos pilares fundamentales: estructura y presentación. En este curso, abordaremos el desarrollo web no como la simple memorización de etiquetas, sino como la construcción de sistemas de información accesibles. HTML (HyperText Markup Language) nos permitirá definir el significado y la estructura del contenido, mientras que CSS (Cascading Style Sheets) nos dará el poder de controlar la apariencia visual, la tipografía y la adaptación a diferentes dispositivos. Este curso elimina las prácticas obsoletas y se centra exclusivamente en estándares actuales.

Módulo 1: Arquitectura y Semántica Web (HTML5)

Enfoque: Entender que HTML es para el significado, no para el estilo.

Temario

  • Historia de la web y funcionamiento cliente-servidor.
  • Sintaxis básica y estructura del DOM (html, head, body).
  • Semántica: Etiquetas estructurales (header, nav, main, section, article, footer).
  • Manejo de Multimedia (Imágenes, Audio, Video) y Enlaces.
  • Formularios modernos y validaciones nativas.

Ejemplo en clase: Creación de la estructura de un artículo de blog periodístico.

Práctica guiada: Construcción de un "Perfil de Usuario" utilizando solo HTML semántico.

Tarea autónoma: Crear la estructura de una página de "Hoja de Vida (CV)" que incluya foto, tabla de habilidades y formulario de contacto.
