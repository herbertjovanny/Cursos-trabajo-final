Módulo 1. Fundamentos del Nuevo Estándar

El "nuevo estándar" de JavaScript se refiere principalmente a ECMAScript 2015 (ES6) y las versiones anuales subsiguientes (ES6+), que introdujeron cambios fundamentales en el manejo del scope (ámbito) y la estructura del lenguaje.

Enfoque: Reacondicionar la mente del programador para dejar atrás var y entender el alcance de bloque, así como optimizar la escritura de código.

Temario

  • Variables y Scope: Diferencias críticas entre let, const y var. El concepto de Temporal Dead Zone.
  • Template Literals: Interpolación de cadenas y etiquetas (Tagged Templates).
  • Arrow Functions: Sintaxis, retorno implícito y el comportamiento léxico del this.
  • Desestructuración: Extracción de datos en Arrays y Objetos.
  • Operadores Modernos: Spread Operator (...) y Rest Parameters para inmutabilidad.

Práctica Guiada: "Refactorización Legacy". Tomar un script antiguo de 50 líneas y reescribirlo usando sintaxis moderna, reduciéndolo a 20 líneas más legibles.

Tarea / Proyecto: El Generador de Perfiles. Crear un script que tome un objeto de usuario complejo, extraiga sus datos clave mediante desestructuración y genere una tarjeta HTML dinámica usando Template Literals
