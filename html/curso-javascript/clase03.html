Módulo 3. Asincronía y El Event Loop

La asincronía en JavaScript permite que el código ejecute operaciones largas sin bloquear el hilo principal, manteniendo la fluidez de la aplicación, mientras que el Event Loop es el mecanismo que gestiona esta asincronía. El Event Loop supervisa constantemente la "Pila de Llamadas" (Call Stack) y una o más "Colas" de tareas asíncronas. Cuando la Pila de Llamadas está vacía, el Event Loop toma la primera tarea de la cola y la mueve a la Pila para su ejecución.

Enfoque: Comprender cómo JavaScript maneja tareas que toman tiempo (peticiones a servidores) sin congelar la interfaz.

Temario

  • El Event Loop: Call Stack, Web APIs y Callback Queue (Teoría esencial).
  • Promesas (Promises): Estados, .then(), .catch() y .finally().
  • Async / Await: La forma moderna de consumir promesas. Manejo de errores con try/catch.
  • Fetch API: Peticiones HTTP nativas (GET, POST, PUT, DELETE).
  • Manejo de promesas paralelas: Promise.all vs Promise.allSettled.

Práctica guiada: "Buscador de Clima". Conectar con una API pública (como OpenWeatherMap) usando fetch y async/await para mostrar el clima actual de una ciudad ingresada por el usuario.

Tarea / Proyecto: Paginación Asíncrona. Crear una galería de imágenes que cargue contenido nuevo (infinite scroll o botones) trayendo datos de una API (como Rick and Morty API o Unsplash), manejando estados de "Cargando..." y errores de red.
