Módulo 2. Lógica de Datos y Programación Funcional

La lógica de datos en JavaScript se refiere a la aplicación de operaciones lógicas para controlar el flujo del programa y tomar decisiones, mientras que la programación funcional es un paradigma que se enfoca en construir programas mediante la composición de funciones puras, tratando los datos de manera inmutable.

Enfoque:Aprender a manipular colecciones de datos sin mutar el estado original, una habilidad esencial para frameworks como React.

Temario

  • Métodos de Array (High Order Functions): map, filter, reduce, find, some, every.
  • Manipulación de Objetos: Object.keys, Object.values, Object.entries y Object.fromEntries.
  • Nullish Coalescing (??) y Optional Chaining (?.): Manejo robusto de datos faltantes o nulos.
  • Estructuras de datos modernas: Introducción breve a Set (para valores únicos) y Map.

Práctica Guiada: "Refactorización Legacy". Tomar un script antiguo de 50 líneas y reescribirlo usando sintaxis moderna, reduciéndolo a 20 líneas más legibles.

Tarea / Proyecto: Dashboard de Analytics. Dado un array de 1000 transacciones ficticias, usar reduce y filter para calcular el total de ventas, ventas por categoría y ticket promedio, mostrando los resultados en consola o DOM.
