Módulo 4. Arquitectura, Módulos y Tooling

La asincronía en JavaScript permite que el código ejecute operaciones largas sin bloquear el hilo principal, manteniendo la fluidez de la aplicación, mientras que el Event Loop es el mecanismo que gestiona esta asincronía. El Event Loop supervisa constantemente la "Pila de Llamadas" (Call Stack) y una o más "Colas" de tareas asíncronas. Cuando la Pila de Llamadas está vacía, el Event Loop toma la primera tarea de la cola y la mueve a la Pila para su ejecución.

Enfoque: Organizar el código como un ingeniero de software, separando responsabilidades y preparando el entorno para producción.

Temario

  • ES Modules (ESM): import y export (default vs named). Cómo dividir el código en archivos lógicos.
  • Clases Modernas: Sintaxis class, propiedades privadas (#propiedad), getters y setters..
  • Almacenamiento en el Cliente: localStorage vs sessionStorage con JSON.
  • Introducción al Tooling: ¿Qué es NPM? y una breve introducción a Vite para levantar un entorno de desarrollo local profesional (dejando atrás el abrir el HTML directamente).

Práctica guiada: "Modularizando la App". Tomar el proyecto del Módulo 3 y dividirlo en archivos: api.js (servicios), ui.js (renderizado), main.js (lógica), usando ES Modules.

Tarea Final / Proyecto Integrador: Gestor de Tareas (To-Do App) Persistente.Una aplicación completa que permita crear, editar y eliminar tareas (Clases). Debe guardar los datos en localStorage, estar dividida en módulos, y usar manipulación del DOM eficiente.
