Módulo 2. Control de Flujo y Estructuras de Datos

Las estructuras de control de flujo y datos en Python dirigen el orden en que se ejecutan las instrucciones, permitiendo la toma de decisiones y la repetición de tareas. Los controles de flujo incluyen condicionales (if, elif, else) y bucles (for, while), mientras que las estructuras de datos principales son listas, tuplas, diccionarios y conjuntos.

Enfoque: Romper la linealidad. Enseñar al programa a tomar decisiones y a repetir tareas eficientemente.

Temario

  • 2.1 Estructuras Condicionales: if, elif, else. Anidamiento de condiciones y lógica booleana optimizada.
  • 2.2 Ciclos (Bucles): while: Para iteraciones basadas en condiciones, y for: Para iteraciones sobre colecciones. Uso de range(), break y continue.
  • 2.3 Listas y Tuplas: Indexación, slicing (rebanado), métodos de listas (append, pop, sort). Diferencias de rendimiento entre tuplas y listas.
  • 2.4 Diccionarios y Sets: Estructuras clave-valor, métodos .get(), iteración sobre claves y valores.

Práctica Guiada: Crear un script de "Nómina Básica" que solicite horas trabajadas y tarifa por hora, calculando impuestos y sueldo neto.

Tarea (Challenge)Analizador de Texto. El usuario ingresa un párrafo. El programa debe devolver: cuántas palabras tiene, cuántas veces aparece cada vocal (usando un diccionario) y devolver el texto invertido.
