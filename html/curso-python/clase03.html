Módulo 3. Modularidad y Funciones

La modularidad en Python es el principio de dividir un programa en módulos más pequeños, y las funciones son el bloque de construcción principal para esto, permitiendo agrupar código reutilizable. La modularidad mejora la organización, mantenibilidad y reutilización del código, haciendo que los programas complejos sean más fáciles de entender y gestionar al dividir el problema en partes más pequeñas y manejables.

Enfoque: El principio DRY (Don't Repeat Yourself). Organización del código y reutilización.

Temario

  • 3.1 Definición de Funciones: Sintaxis def, parámetros posicionales vs. nombrados (keywords). Valores por defecto.
  • 3.2 Retorno de Valores: Uso de return simple y múltiple (desempaquetado de tuplas).
  • 3.3 Alcance (Scope): Variables locales vs. globales. Entendiendo el ciclo de vida de una variable dentro de una función.
  • 3.4 Manejo de Errores (Excepciones): Bloques try, except, else, finally. Cómo evitar que el programa colapse ante errores del usu.

Práctica Guiada: Refactorizar el código del Módulo 1 y 2, encapsulando la lógica en funciones reutilizables dentro de un solo archivo.

Tarea (Challenge)Gestor de Inventario Simple. Crear funciones para agregar_producto, eliminar_producto y mostrar_inventario. El inventario debe ser un diccionario global y las funciones deben manejar errores (ej. intentar borrar un producto que no existe).
