Módulo 1. Fundamentos del Nuevo Estándar

Los fundamentos del lenguaje Python y la lógica secuencial se centran en la ejecución del código línea por línea, en el orden en que está escrito. Esta estructura es la base de la mayoría de los programas y permite un flujo de control predeterminado y ordenado.

Enfoque: Reacondicionar la mente del programador para dejar atrás var y entender el alcance de bloque, así como optimizar la escritura de código.

Temario

  • 1.1 Configuración del Entorno: Diferencias críticas entre let, const y var. El concepto de Temporal Dead Zone.
  • 1.2 Variables y Tipos de Datos Primitivos: Instalación de Python, uso de pip, y configuración de IDEs modernos (VS Code / PyCharm). Diferencia entre modo interactivo y script.
  • 1.3 Operadores y Expresiones: Aritméticos, de comparación y lógicos (and, or, not). Jerarquía de operaciones.
  • 1.4 Entrada y Salida de Datos: Uso avanzado de print() (f-strings para formateo) y input() con conversión de tipos.

Práctica Guiada: Sistema de Login. Un script que simule un acceso con usuario/contraseña, permitiendo solo 3 intentos antes de bloquear el ciclo usando un bucle while.

Tarea (Challenge)El Conversor Universal. Crear un programa que convierta unidades (Celsius a Fahrenheit, Km a Millas, Pesos a Dólares) según la elección del usuario, validando que los números ingresados no sean negativos donde no aplica
